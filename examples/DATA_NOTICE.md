# Example-data notice

`examples/input/example_001_L_0000.nii.gz` is an anonymized lumbar spine MRI
segment provided solely to demonstrate the SpineSPARCC inference workflow.
The public filename uses a generic identifier. Descriptive NIfTI header fields
and header extensions have been cleared; the original clinical identifier is
not included in the public file or repository history.

The example image is not covered by the Apache-2.0 source-code license. Its use
is limited to research evaluation and software demonstration. Users must not
attempt re-identification or use the image for clinical decision-making.
